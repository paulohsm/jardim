Sobre o jardim

Acionamento remoto do portão residencial pela internet.

O que é

Portão Web é um sistema que permite abrir e fechar o portão eletrônico de uma residência a partir de qualquer lugar com acesso à internet, sem depender do controle remoto físico original.

Como usar

Na primeira vez que esta página é aberta em um navegador, é preciso cadastrar um código de acesso (um segredo no formato TOTP, o mesmo tipo usado por aplicativos de autenticação em duas etapas). Esse código é fornecido por quem administra o sistema e é salvo apenas no próprio navegador de quem o usa — nunca é enviado a nenhum servidor nem fica salvo neste site.

Depois desse cadastro único, basta abrir a página e tocar no botão "Acionar portão". A cada toque, o navegador calcula um código válido por apenas 30 segundos e o envia ao dispositivo instalado junto ao portão, que confere o código antes de acionar o motor.

O link "mudar código de acesso", na página principal, permite substituir o código salvo neste navegador por um novo, caso necessário.

Materiais e métodos

Hardware instalado junto ao portão:

  • Módulo ESP-01S (chip ESP8266), responsável por toda a lógica de validação e acionamento;
  • Adaptador USB com conversor WCH CH340G, fixado permanentemente à placa de controle remoto original do portão;
  • Transistor BC548, usado como chave eletrônica entre o ESP-01S e os contatos da placa original.

Comunicação:

  • Protocolo MQTT sobre TLS, usando um serviço de broker em nuvem (EMQX Cloud);
  • O dispositivo junto ao portão se conecta por Wi-Fi e mantém uma conexão permanente com o broker;
  • Esta página se conecta ao mesmo broker a partir do navegador, usando MQTT sobre WebSocket.

Validação e segurança:

  • Algoritmo TOTP (RFC 6238), com janela de validade de 30 segundos;
  • Proteção contra reenvio do mesmo código (replay), bloqueio temporário após tentativas inválidas consecutivas, e exigência de relógio sincronizado por NTP — tudo verificado inteiramente no dispositivo junto ao portão, nunca nesta página;
  • O código TOTP de cada pessoa autorizada nunca é publicado neste site nem enviado a qualquer servidor — fica salvo apenas no armazenamento local do navegador de quem o cadastrou.

Página web:

  • HTML, CSS e JavaScript simples, sem frameworks, hospedados via GitHub Pages;
  • Código-fonte aberto, disponível no repositório do projeto.
